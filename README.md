# Elevvo Pathways Internship ML Portfolio 📊

This repository is the **central hub for my machine learning & data science projects** completed during my **remote internship at Elevvo Pathways**.  

The projects cover a wide range of applied ML workflows, from supervised and unsupervised learning to recommendation systems, time series forecasting, interpretability, and end-to-end pipeline design in Python.

---

## 🚀 Project Index
Below are the internship projects (most recent first). Each project name links to its dedicated repository.

---

### 🛒 [Sales Forecasting](https://github.com/Eyad-27/sales_forecasting)
Predict future product/store sales to support inventory, pricing, and promotion planning.  
Combined classical time-series methods and boosting models with engineered calendar & promotional features.

- **Key Deliverables:**  
  Data consolidation, lag/rolling feature engineering, ARIMA vs. Prophet vs. Gradient Boosting comparison, walk-forward validation, uncertainty visualization dashboards.  

- **Skills Used:**  
  Time-series decomposition, feature engineering, rolling validation, error metrics (MAPE / sMAPE / RMSE), Python (`pandas`, `Prophet`, `scikit-learn`, `XGBoost`, `LightGBM`), visualization.

---

### 🎬 [Movie Recommendation System](https://github.com/Eyad-27/movie_recommendation_system)
Hybrid recommender delivering personalized movie suggestions using **content similarity** and **collaborative filtering**.

- **Key Deliverables:**  
  Metadata parsing (genres, cast, crew), TF-IDF & vector embeddings, cosine similarity engine, matrix factorization collaborative filtering, precision@k & recall@k evaluation, explainable recommendation rationale.  

- **Skills Used:**  
  Recommender systems, sparse matrices, hybrid design, evaluation metrics, Python (`pandas`, `scikit-learn`, `numpy`), optimization & caching.

---

### 🏦 [Loan Approval Prediction](https://github.com/Eyad-27/loan_approval_prediction)
Risk-scoring model to assess loan applications based on demographic & financial attributes with **interpretability focus**.

- **Key Deliverables:**  
  Categorical encoding strategy (ordinal vs. nominal), financial ratio feature engineering, imbalance handling (SMOTE + stratified CV), model comparison (LogReg, Random Forest, XGBoost), SHAP interpretability.  

- **Skills Used:**  
  Classification, fairness & interpretability considerations, ROC-AUC & PR curve analysis, feature engineering, Python (`scikit-learn`, `imbalanced-learn`, `SHAP`).

---

### 🛍️ [Customer Segmentation](https://github.com/Eyad-27/customer_segmentation)
Unsupervised clustering to derive actionable **customer personas** from behavioral & RFM features.

- **Key Deliverables:**  
  Preprocessing & scaling, RFM construction, K-Means + Hierarchical + DBSCAN trials, Elbow / Silhouette / Davies-Bouldin validation, PCA visualization, persona narrative synthesis.  

- **Skills Used:**  
  Clustering, dimensionality reduction, evaluation metrics for unsupervised models, Python (`pandas`, `scikit-learn`), data storytelling.

---

### 🎓 [Student Score Prediction](https://github.com/Eyad-27/student_score_prediction)
Regression model predicting exam performance from study and engagement factors.

- **Key Deliverables:**  
  Exploratory data analysis, preprocessing & feature selection, linear regression modeling, performance evaluation, insight visualization.  

- **Skills Used:**  
  Supervised regression, EDA, feature preparation, Python (`pandas`, `scikit-learn`), data visualization.

- **Python:** `pandas`, `numpy`, `scikit-learn`, `matplotlib`, `seaborn`
